The kit 1.29.0 inside: in `<dsk-markdown>` an embedded picture `![[picture.png|300]]` (or `|300x200`) takes that size, and every embedded picture carries its name in `data-embed` (class `uid-markdown__embed-image`) for a host to find the file by name; an embed of a note or a video gets `data-size`.
