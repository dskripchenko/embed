# ADR-001. Канбан и календарь: разметка в теле виджета

Статус: принят 2026-10-31 (ответы автора на вопросы — в конце). Владелец решений — автор.

## Контекст

Следующий набор виджетов после нотаций (ADR-002 пакета diagrams): канбан
(доски, колонки, карточки) и календарь (события, в том числе
повторяющиеся). Порядок прежний: виджет → embed → плагин Confluence.

Решения автора (2026-10-30):

- данные — **разметка в теле** элемента (макроса), как у диаграмм; файл-
  вложение — запасной источник; серверного состояния, как у `dsk-board`, нет;
- отдельные пакеты не нужны, если хватает элементов embed поверх кита;
- календарь — разметка и события, в том числе повторяющиеся.

Что уже есть в ките `@dskripchenko/ui` 1.17:

- `UidBoard`: колонки, карточки (заголовок, подзаголовок, теги с тоном),
  дорожки, WIP-лимит, разрешённые переходы, перетаскивание с событием `move`
  (соседи в точке броска — для порядка), слоты карточки и шапки колонки;
- `UidCalendar`: только месяц, события на день (`date`, `title`, `color`),
  без времени, многодневных событий, недели и повестки.

## Решения

### 1. Где живёт код

Два плагина embed — `kanban` и `calendar` — с элементами `<dsk-kanban>` и
`<dsk-calendar>` и блоками ```` ```kanban ```` и ```` ```calendar ```` в
markdown. Разборщик и сериализатор разметки — в embed
(`src/plugins/kanban/`, `src/plugins/calendar/`), без зависимостей, с
юнит-тестами на круговой обход.

Чего не хватает кита, дописывается **в ките** (правило «UI-баги и
возможности — в источнике»), минорным релизом `@dskripchenko/ui`:

- `UidBoard`: слоты уже позволяют нарисовать исполнителя, срок и
  приоритет — менять компонент не нужно; добавить только событие «карточка
  добавлена в колонку» (кнопка «+» в шапке), если его нет;
- `UidCalendar`: виды **день** и **неделя** (сетка по часам), **год**
  (12 мини-месяцев с отметками событий), **повестка** (список по дням);
  события со временем и многодневные (полоса через дни); навигация
  «сегодня / назад / вперёд», переключатель вида.

### 2. Разметка канбана

Похожа на markdown, читается без виджета и хорошо выглядит в diff:

```
# Релиз 3.0
lanes: Платежи, Возвраты

## Бэклог
- Подключить СБП #payments {lane: Платежи, who: Анна, due: 2026-11-15}
- Частичный возврат по API #refunds !high {lane: Возвраты}
  Мерчанты просят возвращать часть суммы без звонка в поддержку.
  Ссылка на задачу: [ACME-412](https://jira.example.com/browse/ACME-412)

## В работе {wip: 3}
- [ACME-398](https://jira.example.com/browse/ACME-398) Антифрод v2 {who: Олег}

## Готово {done}
- Вебхуки с подписью HMAC #payments
```

- `# ...` — название доски (необязательно); строки `ключ: значение` до
  первой колонки — настройки доски (`lanes`).
- `## ...` — колонка; в фигурных скобках — её настройки: `wip: N`, `done`
  (колонка «готово»: карточки в ней зачёркнуты в экспорте и считаются
  закрытыми).
- `- ...` — карточка. В строке: `#тег` (теги, тон — по хешу имени или из
  настроек `tags: payments=info, refunds=warning`), `!high` / `!low` —
  приоритет, `{...}` — свойства: `lane`, `who`, `due`, любые свои (видны в
  карточке как подписи). Заголовок — inline-markdown (ссылки, код).
- Строки с отступом под карточкой — её описание (markdown), видно в
  боковой панели по щелчку.

Разбор **без потерь**: у каждой карточки и колонки хранится её диапазон
строк. Перенос карточки, правка в панели, новая карточка меняют только свои
строки; комментарии (`<!-- ... -->`), пустые строки и порядок свойств
остальных не трогаются.

### 3. Разметка календаря

```
# Платёжная платформа: релизы и дежурства
timezone: Europe/Moscow
view: month

2026-11-03 10:00-11:00 Демо релиза 3.0 #release {where: Переговорная 4}
2026-11-10..2026-11-14 Код-фриз #release
every mon 11:00-11:30 Планирование спринта {from: 2026-11-02, until: 2026-12-28, except: 2026-11-30}
every 2 weeks fri 16:00-17:00 Ретро {from: 2026-11-06}
every month 1 Закрытие периода #finance
every month last fri Релиз в прод #release
every year 12-31 Новогодняя заморозка
2026-11-30 Перенос планирования {replaces: 2026-11-30}
```

- Строка события: дата или диапазон дат (`..`), необязательное время или
  интервал времени, заголовок (inline-markdown), `#теги` (цвет — по тегу или
  `tags: release=danger`), `{...}` — свойства (`where`, `who`, `url`, свои).
- **Повторы** — строка с `every`: человекочитаемое подмножество RRULE
  (RFC 5545):
  - `every day` / `every N days`;
  - `every mon[,wed,…]` / `every N weeks mon` — недели по дням;
  - `every month 15` / `every month last fri` / `every month 2nd tue`;
  - `every year 12-31`;
  - границы `from`, `until` или `count`, исключения `except` (список дат).
  Тот же повтор можно записать и как есть: `{rrule: FREQ=WEEKLY;BYDAY=MO}` —
  для переноса из iCal.
- Время — в `timezone` доски (по умолчанию — часовой пояс читателя);
  повторы разворачиваются только в видимом диапазоне.
- Источник `.ics` не делается (решение автора).

### 4. Виды и правка

- **Просмотр**: канбан — колонки с карточками, панель карточки по щелчку,
  фильтр по тегу и исполнителю; календарь — день / неделя / месяц / год /
  повестка (`view` — вид по умолчанию), щелчок по событию — карточка
  события.
- **Правка** — в элементе с `editable` (и в диалоге макроса Confluence):
  - канбан — перетаскивание карточек и колонок, «+» в колонке, правка
    карточки в панели; каждое действие переписывает свои строки разметки;
  - календарь — **билдер событий**: форма события (заголовок, дата или
    диапазон, весь день / время, теги, свойства) и конструктор повтора
    («каждый день / каждые N недель по пн, ср / каждый месяц 15-го или в
    последнюю пятницу / каждый год»; «до даты / N раз / без конца»;
    исключения кликом по дате) — он пишет строку `every …`; перетаскивание
    и растягивание событий в дне, неделе и месяце; щелчок по пустому
    месту — новое событие на эту дату и время;
  - вкладка **«Исходник»** с той же разметкой (ошибки по строкам), как у
    OpenAPI-редактора; правки в обе стороны.
- Событие `dsk:change` с `{ source }`; `name` — скрытое поле формы, как у
  остальных редактируемых элементов.

### 5. Confluence

Макросы `dsk-kanban` и `dsk-calendar` (тело — разметка; источники как
везде: вложение → URL → тело), диалог — визуальный редактор с вкладкой
исходника, превью в редакторе, приложение на виджет (`--widgets=kanban,
calendar`).

- **Правка прямо на странице, как у доски, с замочком.** Кто может
  править страницу, двигает карточки и правит события на странице;
  замочек (параметр макроса `locked`) делает виджет только для чтения для
  всех. В отличие от доски, данные — тело макроса, поэтому сохранение
  на странице — это **новая версия страницы**:
  - сервлет плагина получает новую разметку и id макроса, проверяет право
    правки, находит макрос в storage-формате страницы по `ac:macro-id` и
    заменяет только его тело (и `locked`), версия — «незначительная»
    (`minorEdit`, без рассылки наблюдателям), с комментарием «Канбан:
    перенос карточки»;
  - правки копятся 2–3 с и уходят одной версией, а не каждая отдельно;
  - **конфликт**: сервер сверяет тело макроса, на котором основана правка,
    с текущим; если страницу (этот макрос) изменили — правка
    накатывается по строкам заново (перенос карточки, правка поля — это
    операции над своими строками), а если не получается — виджет
    показывает новую версию и просит повторить; страница в редакторе
    (черновик Synchrony) — правка на странице отклоняется с подсказкой;
  - читатели без права правки видят виджет только для чтения, как при
    закрытом замочке.
- **Экспорт PDF/Word**: картинка, снятая страницей (как у диаграмм), а
  без неё — таблица: канбан — колонки × карточки, календарь — повестка на
  месяц с развёрнутыми повторами. Таблица строится на сервере тем же
  разбором на Java (разметка простая, ~200 строк), чтобы экспорт был
  текстом, а не только картинкой.

### 6. Этапы

1. Кит: `UidCalendar` — день, неделя, год, повестка, время, многодневные
   события, перетаскивание (минор ui).
2. embed: разметка канбана (разбор, сериализация, круговой обход),
   `<dsk-kanban>` просмотр и правка, блок ```` ```kanban ````.
3. embed: разметка календаря и повторы, `<dsk-calendar>` с билдером
   событий, блок ```` ```calendar ````.
4. Документация embed ×4, проверка в браузере, релиз.
5. Плагин Confluence: макросы, диалоги, правка на странице с замочком
   (сервлет сохранения тела макроса, конфликты), экспорт-таблицы, смоук,
   витрина.

## Ответы автора (2026-10-31)

1. На странице — как доска: правка прямо на странице с замочком
   блокировки (раздел 5).
2. `.ics` не нужен.
3. Все виды сразу: день, неделя, месяц, год, повестка.
4. Синтаксис подходит; сразу с билдером событий (раздел 4).
