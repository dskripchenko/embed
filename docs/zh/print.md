# 打印

包含 embed 元素的页面会作为文档打印：屏幕上的控件不会出现在纸上，实时画布或播放器会被替换为其静态形式。

```js
// 可靠的方式：等待所有打印形式就绪，打印，再恢复部件。
const restore = await DskEmbed.print.prepare()
window.print()          // 或宿主程序自己的打印为 PDF
restore()
```

浏览器自带的打印（Ctrl+P / ⌘P）会通过 `beforeprint` 和 `afterprint` 自动完成同样的事；需要一点时间才能生成的形式
（如 API 参考文档），只有在先等待 `prepare()` 后才能确保就绪。页面自己准备好的打印形式不受这些事件影响（打印为 PDF 同样会触发它们）。`prepare()` 会先等待（最多十秒）仍在绘制的部件——正在加载的元素、尚未挂载的 markdown 块——因此内容一出现在页面上即可调用。
`prepare(root)` 可将其限定在页面的一部分。

## 各部件打印的内容

| 部件 | 纸面上 |
|---|---|
| `<dsk-diagram>`、图表块 | 按绘制的样子输出图表 |
| `<dsk-bpmn>`、`<dsk-dmn>` | 整张图，而不只是可见部分；DMN 文件在图下附上每个决策的表格 |
| `<dsk-drawio>` | 所有页面依次排列，有多页时附上页名 |
| `<dsk-flow>`、```` ```flow ```` | 整个流程，无论画布显示的是哪一部分 |
| `<dsk-board>`、```` ```board ```` | 整个白板作为一张图片 |
| `<dsk-openapi>`（参考文档、单个操作） | 静态打印视图：每个操作及其参数、请求体、响应和请求示例，随后是模式；单个操作则为其卡片 |
| `<dsk-openapi>`（块、编辑器）、`<dsk-asyncapi>` | 按屏幕显示，但去掉内部滚动框和固定高度 |
| `<dsk-video>`、```` ```video ```` | 封面图（否则为屏幕上的当前帧）、标题、地址以及带时间的章节 |
| `<dsk-audio>`、```` ```audio ```` | 标题和地址，或播放列表 |
| `<dsk-kanban>`、`<dsk-calendar>` | 看板或所显示的时间段，不含筛选、切换、箭头和锁定按钮 |
| `<dsk-markdown>` | 单栏、不含目录；代码自动换行；块不会被拆到两页 |

全屏按钮、工具栏和 UI 套件的控件永远不会出现在纸上。markdown 中的 ```` ```drawio ```` 块只打印第一页；
`<dsk-drawio>` 元素会打印所有页面。

## 工作原理

每个本身不适合打印的部件都会注册一个打印形式。`prepare()` 生成所有形式，把每个形式放在对应部件之后，并给部件加上
`dsk-print-hidden` 标记；在 `@media print` 下部件被隐藏、形式（`.dsk-print-form`）显示，屏幕上则相反——因此在形式就位期间页面不会移动。
可以在自己的打印 CSS 中通过 `.dsk-print-form` 设置这些形式的样式。
