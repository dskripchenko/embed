# Печать

Страница с элементами embed печатается как документ: то, что на экране
служит управлением, на бумагу не попадает, а живой холст или плеер заменяется
своей статической формой.

```js
// Надёжно: дождаться всех форм, напечатать, вернуть виджеты.
const restore = await DskEmbed.print.prepare()
window.print()          // или печать в PDF самой программы
restore()
```

Собственная печать браузера (Ctrl+P / ⌘P) делает то же сама — через
`beforeprint` и `afterprint`; формы, которым нужно время (справочник API),
гарантированно на месте, только если сначала дождаться `prepare()`.
Формы, подготовленные самой страницей, эти события не трогают (печать в PDF
тоже их вызывает). `prepare()` сначала ждёт (до десяти секунд) виджеты, которые ещё рисуются, —
загружающийся элемент, ещё не смонтированный блок markdown, — поэтому её
можно вызывать сразу, как содержимое оказалось на странице. `prepare(root)`
ограничивает её частью страницы.

## Что печатает каждый виджет

| Виджет | На бумаге |
|---|---|
| `<dsk-diagram>`, блоки схем | схема как нарисована |
| `<dsk-bpmn>`, `<dsk-dmn>` | вся схема, а не видимая часть; файл DMN — с таблицей каждого решения под схемой |
| `<dsk-drawio>` | все страницы подряд, с именами, если их несколько |
| `<dsk-flow>`, ```` ```flow ```` | весь процесс, какую бы часть ни показывал холст |
| `<dsk-board>`, ```` ```board ```` | вся доска одной картинкой |
| `<dsk-openapi>` (справочник, операция) | статический вид для печати: каждая операция с параметрами, телами, ответами и примерами запросов, затем схемы; одна операция — своей карточкой |
| `<dsk-openapi>` (блок, редактор), `<dsk-asyncapi>` | как на экране, без прокрутки внутри и фиксированной высоты |
| `<dsk-video>`, ```` ```video ```` | постер (иначе кадр на экране), название, адрес, главы со временем |
| `<dsk-audio>`, ```` ```audio ```` | название и адрес или плейлист |
| `<dsk-kanban>`, `<dsk-calendar>` | доска или показанный период, без фильтров, переключателей, стрелок и замка |
| `<dsk-markdown>` | одна колонка без оглавления; код переносится; блоки не разрываются между листами |

На бумагу никогда не попадают кнопка полноэкранного режима, панели
инструментов и элементы управления кита. Блок ```` ```drawio ```` в markdown
печатает первую страницу; элемент `<dsk-drawio>` — все.

## Как это устроено

Каждый виджет, который сам по себе не бумага, регистрирует форму для печати.
`prepare()` строит их все, ставит каждую сразу после её виджета и помечает
виджет `dsk-print-hidden`; под `@media print` виджет скрыт, а форма показана
(`.dsk-print-form`), на экране — наоборот, так что страница не сдвигается,
пока формы на месте. Оформить формы можно своим CSS для печати через
`.dsk-print-form`.
